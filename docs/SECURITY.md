# 安全模型

## 1. 默认安全基线

- 服务监听默认 `127.0.0.1`（仅本机）。界面明确显示“仅本机 / 局域网 / 公网（不允许）”。
- 不提供公网暴露的一键开关；`8.8.8.8` 之类的公网地址会被校验直接拒绝。
- 局域网监听（`0.0.0.0`、局域网 IP 或主机名）需要同时满足：
  1. 用户当次启动前完成风险确认（含勾选确认）；
  2. 已启用 API Key 且密钥存储中已配置有效值；
  3. 当前 `llama-server.exe` 的能力快照确认支持 `--api-key`。
- API Key 不提供传输加密；跨不可信网络请使用反向代理/TLS（文档层面说明，非 MVP 功能）。
- 不自动修改 Windows 防火墙、驱动或系统环境变量。

## 2. 密钥存储

- `ISecretStore` 实现使用 Windows DPAPI（CurrentUser）加密，密文保存在 SQLite `Secrets` 表；
  仅当前 Windows 用户可解密，换用户/换机器无法解密（会给出明确错误）。
- 密钥本体：不写入日志、不写入启动历史、不写入命令预览、不写入 JSON 导出、不写入诊断包。
- 命令行预览、日志、历史与 UI 中的键值一律显示为 `******`。
- 由于 API Key 需通过命令行传给服务进程，说明中明确提示：Windows 上同一用户/管理员可能看到进程命令行；
  优先使用程序提供的密钥文件能力（如当前版本支持）是未来增强方向（记录在已知限制中）。

## 3. 日志与诊断脱敏

- 所有实例日志在写入内存与磁盘前经过统一脱敏：已知密钥精确替换 + `--api-key`、`Authorization: Bearer`、
  `api_key=` 等模式匹配。
- 诊断包导出时做二次脱敏；默认将用户目录替换为 `<user-path>`（用户可选择保留完整路径）。
- 诊断包不包含聊天数据库与密钥明文。

## 4. 渲染与注入防护

- Markdown 渲染基于 Markdig AST → WPF FlowDocument：不执行 HTML/脚本，HTML 块按纯文本显示。
- 链接只允许 `http` / `https` / `mailto`，在系统浏览器中打开；其他协议（如 `javascript:`）渲染为纯文本。
- 不使用 WebView2，无脚本执行面。

## 5. 进程与文件安全

- 只终止由本应用启动且通过「PID + 启动时间 + 可执行文件路径」三重校验的进程；禁止按进程名批量 Kill。
- 更新下载仅允许官方 GitHub https 主机；解压拒绝路径穿越/符号链接/压缩炸弹。
- 删除版本文件仅允许发生在 runtimes 目录内；模型文件永不删除（移除登记不影响磁盘）。
- SQLite 恢复前自动备份现有数据库；恢复失败自动回滚。
